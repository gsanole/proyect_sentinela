# Admin Dashboard

React-based admin panel for Art Hub marketplace management.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Create `.env` file:
```bash
cp .env.example .env
```

3. Configure environment variables in `.env`

4. Start development server:
```bash
npm start
```

## Features

- Artist invitation & verification
- Art listing approval/rejection
- Order management
- Payout processing
- Analytics dashboard
- Inventory tracking

## Tech Stack

- React
- React Router
- Material-UI (or Tailwind CSS)
- Axios
- Chart.js (for analytics)

## Build for Production

```bash
npm run build
```
